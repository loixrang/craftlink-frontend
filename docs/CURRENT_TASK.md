Feature: Business profile read-only summary and edit transition (frontend UX improvement; no roadmap feature ID; maintenance work outside the roadmap).

The artisan Business Profile section (`/artisan/profile`) previously kept the full editable form open after a saved profile existed, with only a "Profile saved" message distinguishing saving from editing. It now follows the "Your services" view/edit pattern: with a saved profile the section opens in a read-only summary (profile photo, business name, city/state, availability badge, years of experience, introduction, phone, WhatsApp) with an "Edit" button; "Edit" opens the existing form populated with the saved values (preserving the current photo and the unified profile+photo save flow), a successful "Save profile" refreshes the profile query and collapses the form back into the summary showing the updated information with a temporary "Profile saved" notice, and "Cancel" (shown only when editing an existing profile) discards unsaved changes and any staged image without sending an update request. An artisan with no profile still sees the setup form directly, and a successful first save transitions into the same read-only summary. The unreachable in-form success banner was removed; partial-failure handling (profile saved, image upload failed) keeps the user in edit mode with the staged image for retry. No Delete profile action was added because the backend supports no business-profile deletion (only `DELETE /artisans/me/profile-image`). No endpoint, payload, query key, mutation, route, authentication, backend or visual-design change; no new dependency.

Validation: updated `src/pages/ArtisanManagementPage.test.tsx` (18 tests) — existing-profile tests now reach the form via "Edit"; new tests cover the read-only default state, persisted-information rendering (photo, availability, location, experience, contacts), missing-information fallbacks, the populated edit form, save-and-return with updated data, Cancel discarding changes and staged images without API requests, and the absence of a delete action. The full 126-test suite, lint, typecheck and the production build pass (pre-existing chunk-size warning retained).
