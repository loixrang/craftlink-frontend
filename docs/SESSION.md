# Protected routes and session restoration — FE-AUTH-003

The `/customer/*`, `/artisan/*` and `/admin/*` route families require their exact matching role. Anonymous visitors are redirected to login with their requested path, query and fragment. After login, a normalized same-origin path in the authenticated role's family is restored; external URLs, traversal outside that family and mismatched roles are rejected. Wrong-role access shows an access-unavailable page with a link to the user's dashboard. Dashboard contents remain placeholders.

The shell keeps public navigation and shows only the authenticated role's dashboard plus sign-out. Anonymous visitors see login/registration. While restoration is pending, auth links and protected content are withheld; public discovery remains available.

Only the access token is stored under `craftlink.accessToken` in sessionStorage. The documented decision in DECISIONS.md supersedes FE-AUTH-002's in-memory-only reload behavior. Blocked storage gracefully falls back to in-memory login. No password or trusted role/user information is persisted. Sign-out clears the token and QueryClient caches; cancellation and a new query generation prevent pending restoration from reinstating a signed-out session. Sign-out is local and does not revoke the server token.

Restoration calls the existing GET `/auth/me` endpoint with a bearer header through the service layer. TanStack Query owns the verified user data; tokens are excluded from query keys/results. The service expects `data` to be the current user (`id`, `email`, `role`), validates those fields and strips extras. The frozen contract does not provide a field-level example; live backend compatibility remains unverified. HTTP 401/403 removes storage and returns to anonymous; network/server/malformed-response failures keep protected content hidden and offer explicit retry or sign-out. There is no automatic refresh or invented endpoint. Backend authorization remains authoritative for every protected API operation.

Focused tests cover all roles and cross-role denials, anonymous redirects and return paths, pending/success/rejected/transient restoration, public access, storage failure, logout cancellation and reload behavior. Run `npm.cmd test`, `npm.cmd run lint`, `npm.cmd run typecheck`, `npm.cmd run build` and `git diff --check`. Tests mock HTTP; visual browser checks and live integration are not covered.
